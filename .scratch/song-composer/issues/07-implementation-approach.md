## Question

Which minimal browser implementation, sound source, persistence approach, supported desktop browsers, and hosting arrangement can fulfill the agreed behavior?

Use the feasibility findings and the interaction prototype. Evaluate a browser-local website before adding a server or account system. Check how offline use, piano assets, data recovery, and the selected publishing workflow fit together. Recommend a concrete approach and identify genuine trade-offs; leave personal choices to the owner. Record an ADR only if the chosen trade-off is costly to reverse and needs an explanation for future work.
