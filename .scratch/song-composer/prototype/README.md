# Simple Composer interaction prototype

Open `index.html` directly in a desktop browser. It is self-contained: no installation, network assets, account, or build step is needed. The current local preview is also available at `http://127.0.0.1:8765/` while its preview server is running.

This is disposable prototype code. It keeps composition state only in memory. Reloading or closing the page loses the scratch composition. The triangle-wave sound is temporary, not the final piano. Note audition and playback now use three times the previous note gain, with shared peak compression for dense chords. The part sliders still range from 0% to 100%; metronome levels are unchanged before compression.

The workspace opens with a compact Simple Composer header. The floating **?** button at the bottom right contains the instructions, shortcuts, harmony explanations, guided examples, composition inspector, and prototype limits. Close it with **×**, Escape, or a click outside. The piano has room beneath its keys so the button does not cover note-entry controls. Routine success messages and coaching paragraphs are hidden; errors, label-review warnings, selection state, and drag previews remain available in the workspace.

## Try the workflow

1. Use the entry controls below the timeline to choose a part and position. Choose Default duration beside the piano, or use the synced Note duration menu below the timeline. Chord starts at Half; Melody and Bass start at Quarter. Whole, half, quarter, eighth, sixteenth, dotted values, and quarter/eighth triplets are available. Three quarter triplets fill two quarter-note beats. The choice controls new piano notes and is remembered separately for each part, including through new blank compositions during this page session. Reloading restores the initial defaults. An amber lane and a Piano entry badge identify the part used by the piano; selecting a timeline note also makes its part active. Editing an existing note does not change this default. Click piano keys to add notes. Advance after entry defaults on for Melody: each click moves the orange cursor to the new note's exact end, including across measures. It defaults off for Chord and Bass. The toggle is remembered separately for each part during the session; turn it off to enter simultaneous melody notes. Next step remains available. New entries and edits cannot overlap another note of the same pitch in the same part. Octave-separated pitches and equal pitches in different parts are allowed; a note may begin exactly when the previous one ends.
2. Click a note to select it. Change its pitch, start, or named duration in the side panel, then press Apply edit. Ctrl/Cmd-click or Shift-click toggles individual notes in a group, including across parts. Click empty timeline space to clear the note selection. The inspector shows the group count and instructions when several notes are selected.
3. Left-drag a note's body to move it in time. Snap defaults to Quarter and offers Eighth, Quarter triplet, and Eighth triplet. Sixteenth remains a note duration but is no longer a snap option. Its start snaps to the selected rhythm grid; part, pitch, and duration stay fixed. Dragging any selected note moves the whole group by the same time offset, preserving relative spacing; the dragged note supplies the snap anchor. Drag near the viewport edge to scroll along the timeline. Moving past the song's end adds enough measures on release.
4. Left-drag the right-edge handle to resize. Duration snaps from the dragged note's fixed start. With several notes selected, every duration changes by the same amount; their starts stay fixed. Both gestures preview the whole selection without editing until release, commit one undo step, and cancel with Escape. If any note would become zero-length, start before the song, exceed the prototype limit, or overlap the same pitch in its part, the whole edit is rejected. Red preview outlines and a message identify invalid drags; move back to a valid position or cancel. Right-click without dragging deletes the complete clicked note on release; Undo restores it. Hold the right mouse button and drag horizontally anywhere in the timeline to pan, including from a note body or blank space. Moving at least four pixels makes it a pan, so release cannot delete a note. Panning leaves notes, selections, and the editing cursor unchanged. Escape cancels the pan and restores the previous view. Right-clicking a piano key deletes the complete matching note active at the orange cursor in the selected part, including a note held from earlier. It does not delete equal pitches in other parts or the note that has just ended. No match leaves music and undo unchanged. A matching deletion pauses playback; Undo restores it. The side-panel Delete button remains available.
5. Drag the orange cursor or its handle above the bottom measure labels. It snaps within six screen pixels of note starts and ends, otherwise to the rhythm grid. Playback pauses; the displayed harmony, keyboard colors, and highlighted piano pitches follow the cursor. Highlights include notes in all three parts from their exact starts through their held duration, excluding their exact ends. This preview is silent and does not follow ordinary mouse hover. No notes or undo history change. Arrow keys move a focused cursor handle by the grid; Home and End go to the song boundaries. Entry, Next step, position changes, completed note edits, zoom changes, and returning from playback smoothly center the editing cursor where possible. Reduced-motion preferences use immediate scrolling. Blank viewing space after the final measure lets the end cursor stay centered without adding measures. Manual panning and scrolling remain free until the next editing/navigation action; automatic following does not fight a held right-button drag during playback.
6. Read larger chord names and Roman numerals inside boxes. A new label appears when harmony or the active key changes, including between beats. Measure numbers, meters, and beat marks are below the notes. During playback the entire current box header turns green, including through silence; it clears on pause or completion. Select or hover over a narrow label to read it fully, or increase Zoom. Inversion pairs are stacked vertically without a slash or fraction bar in the inspector and timeline; the lower number aligns with the Roman numeral baseline, and the native choice menu writes “6 over 4” and similar text. The slash in a secondary target such as V/IV remains.
7. Split or merge a box boundary. Notes keep their own starts and lengths, including sustains into later boxes and measures.
8. Press Play, then the same button to Pause. Play resumes. The button itself shows the action; the redundant status beside it is removed. Click a timeline position to choose a different start. A loop repeats the selected whole measures; an entry position inside that range is used for its first pass. Piano clicks during playback audition only and do not advance the editing cursor. Playback clears box selection, including its purple outline and key-edit scope. The view starts following when the playhead passes roughly two-thirds of the visible timeline. Near a box change, it also makes room for the next label if clipped, using a lookahead window of one quarter note or 0.75 seconds, whichever is longer. It avoids previewing a box beyond the playback/loop end. Scrolling brings playback near the left side where the song bounds allow, including on loop returns. Reduced-motion preferences use immediate scrolling. Pausing or editing stops automatic scrolling.
9. Enable Metronome to hear accented measure starts. It clicks quarters in 2/4, 3/4, and 4/4, and dotted quarters in 6/8. There is no count-in. Toggling it does not add composition notes.
10. Toggle Note names and Symbols independently above the piano. Family colors, the legend, tooltips, and accessible pitch names stay available.
11. Click the arrow beside Melody, Chord, or Bass to collapse that part across the timeline. Its small header and note count remain; click again to expand. Notes still play, participate in harmony and piano previews, and remain unchanged. Each header also has a 0–100% volume slider in 5% steps, initially 100%. It controls that part throughout the song, including held notes and piano auditions, and stays available while collapsed. Volume settings last for this page session; 0% mutes that part. They do not change notes, harmony recognition, metronome volume, or musical undo. Row visibility is a session preference, outside musical undo.
12. Click a chord label to select its whole box. Ctrl/Cmd-click adds or removes boxes; Shift-click selects a range. Purple outlines show the selection. In Musical context, choose a key and press Set key for selected boxes. Only those boxes change; unselected gaps and the following music keep their previous keys. Key markers inside selected boxes are replaced; notes and color collections are preserved. Undo restores the whole change once. Clear box selection returns the key control to a change from the cursor until the next key marker. Collection and meter controls still apply at the entry position.
13. Use Key labels: On/Off beside the box tools to show or hide the local song key under every harmony label. It starts on. Hiding it reduces the label-row height without changing key markers, interpretation, or the key shown in the inspector.

Roman numerals follow the chosen recognized chord and the key at that exact position, independently of collection colors. Degrees use the tonic's major scale in both modes: E♭ and A♭ in C minor are ♭III and ♭VI. Triad inversions use 6 and 6/4; seventh inversions use 6/5, 4/3, and 4/2, based on the actual lowest bass/chord note. C/E in C is I6; C7/E is I6/5. Sixth and suspended chords retain their quality and name the bass explicitly when inverted, such as I(add6) [bass A]. Custom labels and unmatched sets have no automatic numeral. Chromatic degrees currently use flat names.

The Roman interpretation menu groups composer-selected readings:

- **Secondary dominant:** major triads and dominant sevenths can target major/minor chords on every chromatic pitch. C7 can be V7/IV; C7/E can be V6/5/IV. The home tonic uses ordinary V, and nested chains are excluded.
- **Tritone substitute:** dominant sevenths can target a major/minor chord a semitone below their root, including the home tonic. D♭7 can be subV7/I.
- **Leading-tone diminished:** diminished triads, diminished sevenths, and half-diminished sevenths can target a root a semitone above. Half-diminished readings are marked as less usual. Choose another recognized chord name to inspect another diminished root. Passing and common-tone roles use custom labels.
- **Modal interchange:** every compatible source among the seven parallel modes is offered when the chord is outside the active major/natural-minor scale. Fm in C major offers Phrygian, Aeolian, and Locrian; D major offers Lydian. A label such as iv · Aeolian records the chosen source without changing key or collection.

The choice appears in the sounding-harmony panel and timeline and can be undone. Hover over a label for its explanation. Interpretations do not force a following resolution or rewrite notes. A choice that becomes unsuitable after a note or key edit receives a review notice; choosing the ordinary degree clears that choice. Chord membership alone does not establish harmonic function.

The three guided examples under **? → Guided examples** build a held bass, moving inner voices, and context changes. Choosing an example replaces current scratch work after confirmation. **? → Inspect the composition** shows the written notes and context markers. Help is nonmodal; dismiss it to inspect the timeline, then reopen it to continue the same example.

Its cursor-boundary regression passed on the existing model; the required preview fix was in the UI playback guard, not note timing. Coverage includes independent rhythms, box edits, complete-note editing, undo/redo, meter changes, collection colors, exact recognition, label scope and mismatch reporting, invalid-edit rejection, song extension, held-note playback, snapped resizing and movement, cursor snapping without musical edits, musical duration labels, metronome timing, Roman numeral conventions and context, advancing step entry, chromatic secondary targets, inversion figures, tritone substitutes, diminished roots, modal sources, chosen-interpretation review rules, same-pitch overlap rejection, piano-key deletion, quarter-triplet snap, selected-box key boundaries and restoration, current-box identification through silence and meter changes, and atomic group movement/resizing with snap, collision rejection, preserved spacing, and one-step undo.

Both script blocks compile. Static source checks found no duplicate element IDs or stale literal element references. The current preview response is checked separately before each handoff; see the latest evidence in the prototype ticket.

## Deliberate limits

The prototype does not save or export projects, insert/delete measures, resize box boundaries, implement the full voicing toolbox, or use the final piano sound. Notes can still extend the song automatically. Maximum length is 256 quarter notes. Exact chord matching covers 14 qualities: major, minor, diminished, augmented, sus2, sus4, 6, m6, 7, maj7, m7, m(maj7), m7♭5, and dim7. Ninths, 6/9, 7♭9, and other extended sets remain playable without automatic names. This limits chord types, not pitch registers or open voicings; incomplete matches display their notes without missing-note suggestions. Display spelling uses practical flat names, so the full context-sensitive spelling policy is not yet implemented.

The repository had no commits or remote when this prototype was started. On October 29, 2026, the owner authorized public source publication as `gnaplds/music-composer` and Netlify hosting. The [root README](../../../README.md) contains the run and deployment instructions; `netlify.toml` copies only the app page into the hosting output. Publication does not settle the production architecture or add project saving.
