# Keep note timing independent of chord-box boundaries

The accepted rules are recorded in [Define note timing and chord-box editing](../../.scratch/song-composer/issues/01-note-timing.md#answer). Separating musical timing from the visual boxes lets a bass or melody continue while other voices move, and lets the composer reorganize boxes without changing the phrase's rhythm. Treating box resizing as time stretching would couple visual organization to changes in the music; the owner chose separate operations for those tasks. The storage representation remains a later implementation decision.
