# Store projects locally and use portable files for backup

The accepted rules are recorded in [Define project recovery and file exchange](../../.scratch/song-composer/issues/05-project-recovery.md#answer). Browser-local autosave supports the owner's personal desktop writing workflow without an app account or cloud project service. Its main cost is that clearing browser storage can remove the projects, and other browsers or computers do not share them automatically. Full project files provide explicit backup and transfer, with restoration into a new copy to protect existing work. MIDI serves exchange with music software; it does not guarantee restoration of the app's editing state. This boundary keeps the first release small while making its data-recovery limits clear.
