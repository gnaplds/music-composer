# Keep musical context independent of written notes

The accepted rules are recorded in [Define context changes and harmonic colors](../../.scratch/song-composer/issues/03-musical-context.md#answer). Song key does not uniquely determine a Barry Harris collection, so the three context timelines—key, meter, and collection—remain independent. Treating a context edit as a note edit would change the composer's phrase while they were changing its interpretation or measure layout. Preserving the written pitches and timing keeps those actions separate, while explicit insertion and deletion of measures remain operations that change musical time.


On October 30, 2026, the owner added an [empty-box entry default](../../.scratch/song-composer/issues/03-musical-context.md#empty-box-key-defaults--october-30-2026): advancing or writing into empty/new boxes initializes their keys from the active collection. This is an entry convenience, not continuous coupling. Collection edits alone still leave keys and notes unchanged, and occupied boxes retain their keys.
